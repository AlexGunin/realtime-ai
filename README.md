# 💬 Real-time AI Chat Interface

Простой и красивый веб-интерфейс для общения с AI в реальном времени. Поддерживает streaming ответов для мгновенного отображения текста по мере генерации.

## ✨ Основные возможности

- 🚀 **Real-time streaming** - текст появляется по мере генерации
- 💬 **История разговора** - backend хранит контекст беседы
- 🎨 **Современный UI** - красивый адаптивный интерфейс
- ⚡ **Легкий и быстрый** - чистый JavaScript, без тяжелых фреймворков
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🏗️ Архитектура

Проект состоит **только из фронтенда**. Backend должен быть развернут отдельно и соответствовать API контрактам.

```
realtime-ai/
├── index.html          # Основная страница
├── styles.css          # Стили интерфейса
├── app.js             # Логика приложения
├── config.js          # Конфигурация подключения к backend
├── API_CONTRACTS.md   # Спецификация API для backend
└── package.json       # Зависимости для разработки
```

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонировать репозиторий
git clone <url>
cd realtime-ai

# Установить зависимости для dev-сервера
npm install
```

### 2. Конфигурация

Откройте `config.js` и укажите URL вашего backend:

```javascript
const CONFIG = {
    API_BASE_URL: 'http://localhost:3000',  // Измените на URL вашего backend
    // ...
};
```

### 3. Запуск

```bash
# Запустить dev-сервер
npm run dev
```

Приложение откроется в браузере по адресу `http://localhost:8080`

### 4. Альтернативный запуск

Можно просто открыть `index.html` в браузере, но для корректной работы с CORS рекомендуется использовать web-сервер.

## 🔌 Backend Requirements

Backend должен реализовывать API согласно спецификации в **[API_CONTRACTS.md](API_CONTRACTS.md)**

### Основные требования:

1. **Streaming endpoint** - `POST /api/chat` с Server-Sent Events (SSE)
2. **Clear endpoint** - `POST /api/clear` для очистки истории
3. **CORS** - разрешить запросы с фронтенда
4. **История** - хранить контекст разговора по conversationId

### Пример ответа (SSE):

```
data: {"type": "chunk", "text": "Привет"}
data: {"type": "chunk", "text": "!"}
data: {"type": "done"}
```

Подробнее см. [API_CONTRACTS.md](API_CONTRACTS.md)

## 📝 Использование

1. **Отправка сообщения**: Введите текст и нажмите Enter или кнопку отправки
2. **Новая строка**: Shift + Enter для переноса строки
3. **Очистка истории**: Кнопка "Очистить историю" в шапке

## 🐛 Troubleshooting

### Backend не доступен

- Проверьте, что backend запущен
- Проверьте URL в `config.js`
- Проверьте CORS настройки на backend
- Откройте DevTools → Network для просмотра ошибок

### Не работает streaming

- Убедитесь, что backend отправляет `Content-Type: text/event-stream`
- Проверьте формат SSE (должно быть `data: {...}\n\n`)
- Проверьте, что backend не буферизует ответ

### Ошибка 403 при запросах

- Проверьте CORS на backend
- Убедитесь, что разрешены POST запросы

## 🛠️ Development

### Структура кода
